# Portafolio de programación de Mariana Loaiza Hernández

Sitio público de práctica con proyectos web sencillos y una hoja de vida.

**Portafolio:** https://loaizamariana333-pixel.github.io/portafolio-programacion-mariana-loaiza/

## Archivos

Los archivos se encuentran en la raíz del repositorio para que GitHub Pages pueda abrirlos directamente:

- `index.html`: presentación, habilidades y proyectos.
- `styles.css`: estilos del portafolio.
- `hoja-de-vida.html`: hoja de vida de una página, con opción de imprimir o guardar como PDF.
- `calculadora.html` y `calculadora.js`: calculadora básica.
- `tareas.html` y `tareas.js`: lista de tareas con almacenamiento local.
- `quiz.html` y `quiz.js`: cuestionario interactivo.
- `demo.css`: estilos compartidos por los tres ejercicios.

## Proyectos de práctica

### Calculadora básica

- **Objetivo:** resolver operaciones aritméticas sencillas.
- **Tecnologías:** HTML, CSS y JavaScript.
- **Aporte:** organicé los archivos, revisé la navegación y publiqué el ejercicio en GitHub Pages.
- **Aprendizaje que practica:** operadores, eventos y validación de entradas.

### Lista de tareas

- **Objetivo:** agregar, completar y borrar tareas, guardándolas en el navegador.
- **Tecnologías:** HTML, CSS y JavaScript.
- **Aporte:** organicé los archivos, revisé la navegación y publiqué el ejercicio en GitHub Pages.
- **Aprendizaje que practica:** arreglos, eventos, manipulación del DOM y almacenamiento local.

### Quiz de programación

- **Objetivo:** responder preguntas y calcular un puntaje.
- **Tecnologías:** HTML, CSS y JavaScript.
- **Aporte:** organicé los archivos, revisé la navegación y publiqué el ejercicio en GitHub Pages.
- **Aprendizaje que practica:** arreglos, condiciones, funciones y seguimiento del puntaje.

Estos son ejercicios de práctica preparados con apoyo para este portafolio. Revisa y adapta el código y asegúrate de poder explicar cómo funciona. La guía del proyecto pide trabajos reales que puedas explicar; puedes sustituir o complementar estos ejercicios con proyectos que hayas realizado en clase.
