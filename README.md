# Portafolio de programación de Mariana Loaiza Hernández

Sitio web de práctica para presentar aprendizajes de la formación técnica en programación. Está construido con HTML, CSS y JavaScript, y se puede publicar con GitHub Pages.

## Contenido

- `index.html`: presentación, habilidades y enlaces a los proyectos.
- `styles.css`: estilos adaptables a celular y computador.
- `proyectos/`: tres ejercicios funcionales para estudiar y personalizar.
- `hoja-de-vida.html`: hoja de vida de una página, lista para imprimir o guardar como PDF.

## Proyectos incluidos

1. Calculadora básica: operaciones y validación de entradas.
2. Lista de tareas: eventos, arreglos y almacenamiento en el navegador.
3. Quiz de programación: preguntas, condiciones y puntaje.

Son ejercicios de práctica preparados para este portafolio. Revisa el código, cambia lo que quieras y asegúrate de poder explicar cada parte antes de presentarlos como evidencia de tus aprendizajes.

## Ver el sitio

Abre `index.html` en un navegador. Para publicarlo, crea un repositorio público llamado `portafolio-programacion-mariana-loaiza`, sube el contenido de esta carpeta y activa GitHub Pages desde **Settings → Pages → Deploy from a branch → main → /(root)**. Después prueba el enlace publicado y agrégalo a `hoja-de-vida.html` donde aparece `ENLACE DE GITHUB PAGES`.

## Personalización antes de entregar

- Revisa que el nombre de la institución, el grado y el año estén correctos.
- Cambia las descripciones para que reflejen lo que comprendes y hayas adaptado.
- Puedes agregar proyectos reales realizados en clase, con autorización para compartirlos.
- Mantén privada cualquier clave, contraseña, dato personal o información de terceros.
- Imprime la hoja de vida desde el navegador y selecciona “Guardar como PDF”.
